# Промт: hero-секция сайта ветклиники «ВЕТМИР»

**Собери одностраничную hero-секцию для ветеринарной клиники «ВЕТМИР» на React + Tailwind CSS + Lucide React. Секция занимает высоту вьюпорта без прокрутки, три брейкпоинта (mobile, tablet md, desktop lg+). Стек: Vite + TypeScript.**

Клиника работает **круглосуточно** — это главный дифференциатор, он должен читаться с первой секунды. Экран обслуживает два разных состояния посетителя:

1. **Паника в 3 ночи** — нужен телефон и адрес, крупно, без прокрутки.
2. **Спокойный поиск специалиста** — нужны врачи, компетенции, цены.

Оба должны решаться в первом экране, не конкурируя.

## Шрифты (Google Fonts)

- **Onest** (400, 500, 600, 700) — интерфейс и текст. Кириллица родная, замена не нужна.
- **Playfair Display** (400) — только заголовок обложки.

```html
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600;700&family=Playfair+Display:wght@400&display=swap" rel="stylesheet">
```

```css
.font-serif-display { font-family: 'Playfair Display', Georgia, serif; }
body { font-family: 'Onest', 'Inter', system-ui, sans-serif; }
```

**Почему не DM Serif Display и не Inter.** DM Serif Display не содержит кириллицы — браузер молча свалится в Times, и заголовок будет выглядеть дёшево. Playfair Display — та же высококонтрастная антиква, кириллица есть. Onest вместо Inter: родная кириллица, более характерный рисунок, не «дефолт по умолчанию».

**Проверка подстановки — замером ширины, а не глазами:**

```js
const p = document.createElement('span')
p.style.cssText = "position:absolute;visibility:hidden;font-size:100px;font-family:'Playfair Display',serif"
p.textContent = 'Круглосуточно'
document.body.appendChild(p)
console.log('ширина кириллицы:', p.getBoundingClientRect().width)
p.remove()
```

## Палитра

Ключевое требование: **весь текст ≥ 4.5:1**. Аудитория ветклиники сильно смещена к 45+, а старый сайт клиники проваливал контраст на фирменном зелёном (3.65:1). Контрастность каждой пары ниже проверена.

| Роль | HEX | Контраст |
|---|---|---|
| Фон полотна | `#EDF6EF` | — |
| Поверхность (карточки) | `#FFFFFF` | — |
| Тёмно-зелёный (заголовки, основной текст) | `#123B28` | 13.8:1 на фоне |
| Брендовый зелёный (кнопки, иконки, ссылки) | `#0A6B45` | 6.5:1 на белом |
| Зелёный hover | `#08573A` | — |
| Оранжевый акцент (экстренное действие) | `#C2410C` | 4.8:1 с белым текстом |
| Оранжевый hover | `#9A3412` | — |
| Вторичный текст | `#4A5A50` | 7.2:1 на фоне |
| Хайрлайн-границы | `rgba(18,59,40,0.10)` | — |

**Правила использования.** Зелёный — это база бренда, не акцент: им набраны заголовки, иконки, вторичные кнопки. **Оранжевый — единственный акцент, максимум два появления на экран**: круглосуточный телефон в шапке и главная CTA. Никаких третьих цветов, никакого чистого чёрного `#000`, никакого голубого и мятного (на старом сайте они давали 2.1:1).

## Ассеты

Логотип — инлайновый SVG-вордмарк, не растр. Старый логотип клиники — PNG 1202×300 под контейнер 355×89; так делать нельзя.

**Вордмарк:** «ВЕТМИР» гротеском Onest 700, `letter-spacing: 0.02em`, цвет `#123B28`; слева — знак: скруглённый крест из двух прямоугольников (`rx=3`) в круге `#0A6B45`, крест белый. Габарит 168×40 на десктопе, 124×30 на мобильном.

**Фотографии — плейсхолдеры** `https://picsum.photos/seed/{seed}/{w}/{h}`. Точные пропорции обязательны: под них сверстана сетка, реальные фото подставляются без переверстки.

| Слот | Плейсхолдер | Формат | Что подставить в проде |
|---|---|---|---|
| Карточка услуги | `seed/vetmir-home/520/514` | 260:257 | Врач с саквояжем у двери |
| Видеокарточка | `seed/vetmir-video/354/574` | 177:287 | Кадр из видеоотзыва |
| Фото слева | `seed/vetmir-dog/900/1000` | ~9:10 | Собака после приёма |
| Фото по центру (самое высокое) | `seed/vetmir-vet/1100/1400` | ~11:14 | Врач с животным на руках |
| Фото справа | `seed/vetmir-cat/900/1000` | ~9:10 | Кот в кабинете |
| Аватары врачей ×3 | `seed/vetmir-doc1..3/128/128` | 1:1 | Портреты из `/about/personal/` |

Все `<img>` — с `width`/`height` или `aspect-ratio`, `loading="lazy"` на всём, кроме центрального фото и логотипа. Формат в проде — WebP; на старом сайте отдавались JPEG 3203×1100 под контейнер 375×129.

## Шапка

Во всю ширину, `px-12` на десктопе, `py-4`, `relative z-30`, `shrink-0`.

**Слева:** вордмарк.

**По центру (скрыт ниже `md`):** «Услуги», «Врачи», «Цены», «Отзывы», «Контакты» — `text-sm font-medium`, `gap-7`, цвет `#4A5A50`, активный `#123B28`. Ниже `md` пункты не сжимаются, а прячутся: на 375px русское меню шире экрана.

**Справа:**

- Кнопка поиска — круг 44×44, хайрлайн-граница, иконка `Search`. Скрыта ниже `sm`. Ведёт в поиск по прайсу, не по сайту.
- **Круглосуточный телефон** — пилюля `bg-[#C2410C]`, белый текст, иконка `Phone`, высота 44px: иконка + `8 (499) 579-81-81` + подпись `10px/500` «круглосуточно». Ниже `md` схлопывается в оранжевый круг 44×44 только с иконкой, `aria-label="Позвонить круглосуточно"`. **На мобильном это главное действие экрана** — оно не прячется никогда.
- Кнопка «Записаться» — контурная, `border-[#0A6B45]`, текст `#0A6B45`, скрыта ниже `md`.
- Бургер — круг 44×44, виден только ниже `md`.

Никаких корзины, избранного и аватара: у клиники нет магазина в первом экране, а «4» и «1» на бейджах у медицинского сайта читаются как счётчик проблем.

**Все интерактивные элементы — минимум 44×44.** На старом сайте 137 из 203 кликабельных элементов были мельче.

## Десктоп (lg+)

### Текстовый слой (z-5)

По центру, `px-12 pt-[5.4rem]`.

Заголовок: `.font-serif-display`, цвет `#123B28`, `text-[clamp(44px,6.4vw,92px)]`, `leading-[0.98]`, `tracking-[-0.02em]`.

```
Круглосуточно
рядом с вами
```

Верхняя граница clamp — 92px, а не 110px: «Круглосуточно» — 13 знаков, при 110px строка упирается в край на 1280px. **Замерить перед сдачей на 1280 / 1440 / 1920**, запас `inner - line` должен быть > 0.

Каждое слово — `inline-block` с классом `.animate-word-pop` и ступенчатой задержкой. Обёртки-маски строк: `overflow:hidden; padding-bottom:.14em` — без этого обрежутся выносные «р», «у», «д».

Подзаголовок под ним: `text-[17px] leading-[1.55] text-[#4A5A50] max-w-[46ch]` — «Ветеринарная клиника в Москве. Приём, хирургия, стационар и вызов врача на дом — 24/7, без выходных.»

### Карточка услуги (слева)

`absolute top-[50px] left-12`, ширина `clamp(160px,14vw,260px)`.

Фото `aspect-[260/257] rounded-2xl overflow-hidden`. В правом нижнем углу — круглая кнопка `bg-[#0A6B45]` 40×40 с иконкой `ArrowUpRight`, ведёт на `/services/vyzov-vracha-na-dom/`.

Под фото: «Вызов врача на дом» — `text-[#4A5A50] text-[clamp(12px,1vw,14px)]`; ниже «от 1 600 ₽» — `text-[#123B28] font-semibold text-[clamp(15px,1.3vw,19px)]`, цифры с `font-variant-numeric: tabular-nums`.

Цена реальная, из прайса клиники. Никаких `99.99` и выдуманных чисел.

### Видеокарточка (справа)

`absolute top-[50px] right-12`, ширина `clamp(120px,10vw,177px)`.

Фото `aspect-[177/287] rounded-2xl`. По центру ближе к низу — круглая кнопка `bg-[#0A6B45]` 48×48 с иконкой `Play`, белой.

Подпись под кнопкой: «Видеоотзывы владельцев» — `text-white text-[clamp(11px,0.9vw,13px)] leading-[1.35]`, на затемняющем градиенте снизу.

Если видео нет — заменить `Play` на `ArrowUpRight`, подпись на «Отзывы владельцев», ссылку на `/otzivi/`. Не имитировать плеер там, где его нет.

### Три фотографии снизу

`absolute bottom-0 left-0 right-0`, `z-10`, `flex items-end`, без зазоров.

- Левое: `flex-1`, `maxHeight: min(70vh, 55vw)`
- Центральное: `flex-[1.265]`, `maxHeight: min(85vh, 70vw)`
- Правое: `flex-1`, `maxHeight: min(70vh, 55vw)`
- Все: `w-full h-auto block object-cover object-top`

Стык фото с фоном смягчить градиентом сверху каждой картинки: `linear-gradient(to bottom, #EDF6EF 0%, rgba(237,246,239,0) 18%)`.

### Оверлеи поверх фотографий

Все — на `bottom: clamp(20px, 4vh, 50px)`, поверх локального затемнения (не сплошной плашки, а ступенчатого градиента в цвет, иначе на стыке видна полоса).

**Слева — «3000+ операций»:** число `font-serif-display text-[clamp(28px,2.6vw,44px)] text-white`, подпись «операций провели наши врачи» `text-white/85 text-[13px]`. Рядом — стек из трёх аватаров врачей 32×32 с `ring-2 ring-white` и наложением `-ml-2`, четвёртым — круг `bg-[#0A6B45]` с иконкой `Plus`.

**По центру — CTA:** заголовок «Помощь животным в любое время суток» — `text-white font-serif-display text-[clamp(20px,2vw,32px)] leading-[1.15] max-w-[16ch]`. Под ним пилюля `bg-[#C2410C] text-white h-12 px-6 rounded-full` с текстом «Записаться на приём» и иконкой `ArrowRight`.

**Справа — доверие:** иконка `Star` заливкой `#C2410C`, значение `{{RATING}}` и подпись «на Яндекс.Картах». **Значение подставить реальное; не выдумывать.** Пока рейтинг не подтверждён — вместо блока выводить «10 лет / безупречной работы» (цифра проверенная).

## Анимации

| Класс | Кейфреймы | Длительность | Кривая |
|---|---|---|---|
| `.animate-fade-up` | `translateY(30px)`, `opacity 0` → 0/1 | 0.8s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-fade-in` | `opacity 0→1` | 0.6s | `ease-out` |
| `.animate-slide-up` | `translateY(60px)` → 0 | 0.9s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-slide-in-left` | `translateX(-40px)` → 0 | 0.8s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-slide-in-right` | `translateX(40px)` → 0 | 0.8s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-text-reveal` | `translateY(40px) skewY(3deg) blur(4px)` → none | 1s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-word-pop` | `translateY(60px) scale(.7) rotate(-4deg) blur(8px)` → перелёт → покой | 0.9s | `cubic-bezier(.34,1.56,.64,1)` |
| `.animate-scale-in` | `scale(.85)` → 1 | 0.7s | `cubic-bezier(.16,1,.3,1)` |
| `.animate-photo-reveal` | `translateY(80px) scale(1.02)` → norm | 1.1s | `cubic-bezier(.16,1,.3,1)` |

Все с `animation-fill-mode: both`. `.animate-word-pop` стартует с `opacity: 0`.

Задержки: `.delay-100` … `.delay-1200` шагом 100 мс.

**Анимировать только `transform` и `opacity`.** Никаких `top`, `left`, `width`, `height`.

### Гейт запуска

Каскад не должен стартовать, пока грузятся шрифты, иначе зритель увидит скачок подстановки посреди появления:

```js
Promise.all([document.fonts.ready]).then(start)
setTimeout(start, 3000)  // страховка: сеть не должна держать экран
```

`start` обязан быть идемпотентным.

### Доступность движения

```css
@media (prefers-reduced-motion: reduce) {
  [class*="animate-"] {
    animation: none !important;
    opacity: 1 !important;
    transform: none !important;
  }
}
```

Контент обязан остаться видимым. Отключение анимации, оставляющее `opacity: 0`, даёт пустой экран — на медицинском сайте это отказ в обслуживании.

### Наведение только там, где есть мышь

```js
if (matchMedia('(hover:hover) and (pointer:fine)').matches)
  document.body.classList.add('hoverable')
```

Все `:hover`-правила пишутся как `.hoverable .element:hover`. Ничего важного нельзя прятать под `opacity-0` до наведения.

## Порядок каскада

1. Шапка проявляется — 100–300 мс; оранжевый телефон **последним, с пружиной** (он должен поймать взгляд).
2. Слова заголовка выскакивают — 200–600 мс с шагом.
3. Боковые карточки въезжают — 600–700 мс.
4. Нижние фото поднимаются — 600–900 мс, центральное первым.
5. Оверлеи и CTA — 1000–1200 мс.

Общая длительность до последнего элемента — **не больше 1.4 с**. Дольше зритель начинает ждать, а часть аудитории пришла сюда в панике.

## Техническая рамка

- Контейнер: `h-[100dvh] flex flex-col overflow-hidden`. **Не `h-screen`** — на iOS Safari он даёт скачок вёрстки при появлении адресной строки.
- Шапка `shrink-0`, hero `flex-1 flex flex-col overflow-hidden`.
- Раскладки переключаются показом/скрытием (`hidden lg:flex`), а не только CSS-медиазапросами.
- Fluid-типографика и отступы через `clamp()`.
- Иконки Lucide: `Search`, `Phone`, `Menu`, `Star`, `ArrowUpRight`, `Play`, `ArrowRight`, `Plus`.
- `<html lang="ru">` — на старом сайте атрибут отсутствовал.
- Каждой картинке — осмысленный `alt`; иконкам-ссылкам — `aria-label`.
- Видимый `focus-visible` контур на всех кликабельных элементах: `outline: 2px solid #0A6B45; outline-offset: 2px`.
- Первым элементом DOM — скрытая ссылка «К содержимому», всплывающая по фокусу.

## Чек-лист перед сдачей

1. Кириллица берётся из Playfair Display — проверено замером ширины пробника, не глазами.
2. `document.documentElement.scrollWidth === clientWidth` — горизонтальной прокрутки нет.
3. Заголовок не упирается в край на 375 / 800 / 1024 / 1440 / 1920.
4. Ни один текст не даёт контраст ниже 4.5:1 (проверить оверлеи поверх фото — там фон переменный).
5. Все кликабельные элементы ≥ 44×44.
6. Телефон достижим и кликабелен на 375px без прокрутки и без раскрытия меню.
7. `prefers-reduced-motion` не прячет контент.
8. Каскад завершается даже при мёртвой сети.
9. Числа на экране — только реальные: 3000+ операций, 10 лет, от 1 600 ₽. `{{RATING}}` либо подставлен, либо блок заменён.
10. Консоль чистая.
